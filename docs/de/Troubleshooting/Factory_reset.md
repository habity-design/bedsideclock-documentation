
# Auf Werkseinstellungen zurücksetzen

Folge dieser Anleitung, wenn du deinen Wecker auf die Werkseinstellungen zurücksetzen musst.
Dabei werden alle gespeicherten Einstellungen wie Alarme und die aktuelle Uhrzeit gelöscht.

**So geht's**
Geh zu „More“ > „Factory reset“ > „Confirm reset“.

> [!NOTE] HINWEIS
> Dadurch werden alle gespeicherten Einstellungen gelöscht und die Reisesperre wird aktiviert.
